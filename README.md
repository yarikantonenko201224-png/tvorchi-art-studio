# TVORCHI — сайт студии

Next.js 15 (App Router) + TypeScript. Данные пока статические, из `lib/data.ts`;
позже заменяются на Supabase — интерфейсы останутся теми же, компоненты трогать не придётся.

## Запуск

```bash
cd C:\Tvorchisayt\site
npm install
npm run dev
```

Откроется на http://localhost:3000

**Проверка с телефона.** Мобильный — главный сценарий, поэтому смотреть надо на телефоне:

```bash
npm run dev -- -H 0.0.0.0
```

Затем на телефоне в той же Wi-Fi открыть `http://<IP-компьютера>:3000/i`
(IP покажет `ipconfig`). Ещё честнее — отправить себе эту ссылку в Direct
и перейти по ней из Instagram: тогда проверяется именно тот встроенный браузер,
под который всё спроектировано.

## Решения, которые легко случайно сломать

- **Шрифт Rubik, не Outfit.** У Outfit нет кириллицы — украинский текст падал бы
  на системный шрифт. Проверено по метаданным Google Fonts.
- **16px в полях ввода.** Меньше — и iOS зумит страницу при фокусе.
- **Возраст в форме ограничен группой.** Группа 5–6 не принимает ребёнка 12 лет;
  чип «інший вік» возвращает к выбору группы, чтобы не было тупика.
- **Цены табличными цифрами** (`.t-price`) — иначе суммы прыгают при пересчёте.
- **Состояние воронки в React-стейте, не в localStorage.** Во встроенном браузере
  Instagram хранилище может обнуляться.
- **Логотип временный.** `components/Logo.tsx` — клякса по мотивам фирменной,
  заменяется на настоящий SVG (см. `docs/BRAND-ASSETS.md`).

## Анонсы: как их ведёт администратор

Сейчас источник — опубликованная Google-таблица, позже заменится на админку в CRM.
Код это переживёт: меняется только `getAnnouncements()` в `lib/announcements.ts`,
страницы и компоненты остаются как есть.

**Колонки таблицы** (первая строка, латиницей):

```
id | title | cover | starts_at | ends_at | place | age | short | full | price | seats | link | active
```

- `starts_at` / `ends_at` — формат `2026-09-20 13:00`. Если `ends_at` пустой,
  событие живёт до конца дня начала.
- `price` — свободный текст: «безкоштовно», «350 ₴», «вхід вільний · МК за донат від 50 ₴».
- `seats` — число свободных мест. `0` выводит «місць немає» и убирает кнопку записи.
  Пусто — блок мест не показывается.
- `active` — `FALSE` снимает событие с публикации досрочно.
- `cover` — прямая ссылка на картинку афиши (необязательно).

**Публикация:** Файл → Опублікувати в Інтернеті → нужный лист → CSV → Опублікувати.
Ссылку положить в `.env.local`:

```
ANNOUNCEMENTS_CSV_URL=https://docs.google.com/spreadsheets/d/…/pub?output=csv
```

Пока переменной нет, работают демо-данные из `lib/announcements.ts` — это реальные
анонсы студии из Instagram, они же образец заполнения.

Данные кэшируются на 5 минут (`revalidate: 300`), то есть правка в таблице появляется
на сайте в течение пяти минут. Если таблица недоступна, сайт не падает — показывает
демо-данные.

**Сортировка не по дате начала, а по дате окончания.** Месячная акция, стартовавшая
две недели назад, не должна оттеснять событие, которое послезавтра: сверху всегда то,
что сгорит раньше. Прошедшие уходят из списка сами.

## Десктоп

Мобильная вёрстка написана без медиазапросов — она базовая. Всё десктопное собрано
в одном блоке `@media(min-width:900px)` в конце `globals.css`. Это значит, что править
десктоп можно без риска сломать телефон: мобильный туда просто не заходит.

Что меняется на широком экране:

- появляется шапка с навигацией (`components/Header.tsx`), липкая нижняя панель скрывается —
  её роль играет кнопка в шапке;
- первый экран становится двухколоночным, сцена крупнее (предметы и знак масштабируются
  через переопределение конечного состояния анимации, сама анимация не трогается);
- карточки раскладываются в 2 колонки, расписание — в 3, чтобы неделя читалась целиком;
- текстовые блоки ограничены ~78 символов в строке: на всю ширину читать тяжело.

Брейкпоинт один — 900px. До него планшет ведёт себя как телефон, и это осознанно:
одна колонка на планшете читается лучше, чем сжатые две.

## Секреты и переменные окружения

Репозиторий публичный, поэтому правило жёсткое: **в коде нет ни одного ключа.**

- локально — `.env.local` (он в `.gitignore` и не коммитится);
- на проде — Vercel → Settings → Environment Variables;
- в репозитории — только `.env.example` с именами переменных и пустыми значениями.

Если ключ всё-таки попал в коммит, менять его в файле бесполезно: он остаётся в истории git.
Такой ключ нужно отзывать и выпускать заново (в Telegram — `/revoke` у @BotFather).
